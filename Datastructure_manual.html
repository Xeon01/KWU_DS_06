Search/Datastructure.hpp 레퍼런스 매뉴얼

STL 컨테이너·알고리즘 헤더 없이 기본 C++17 문법으로 직접 구현한 namespace ds 자료구조 라이브러리

1. 설계 원칙 및 의존성

Search/Datastructure.hpp는 <vector>, <queue>, <set>, <unordered_map>, <unordered_set>, <array>, <tuple>, <utility>, <algorithm>, <functional> 등 STL 컨테이너·알고리즘 헤더를 전혀 포함하지 않습니다.

  • 포함 헤더: <cstddef>, <cstdint>, <new>(placement new / ::operator new), <stdexcept>(std::out_of_range)만 사용합니다.
  • 메모리 안전성: 동적 컨테이너(Vector, Queue, HashMap, OrderedSet) 모두 Rule of Five(소멸자, 복사 생성/대입, 이동 생성/대입)와 예외 안전성을 구현했습니다.
  • 헤더 온리(Header-only): #pragma once 단일 헤더로 Graph.hpp에 포함되어 Graph.cpp, Pathfinder.cpp에서 바로 사용됩니다.

2. 탐색 엔진 STL 교체 매핑

기존 STL 직접 구현 자료구조 내부 구현 방식 탐색 엔진 내 사용 위치
std::vector<T> ds::Vector<T> 2배 확장 동적 배열 + placement new 노드/간선 목록, 인접 리스트, 다익스트라 거리·경로 배열
std::array<T, N> ds::Array<T, N> 고정 크기 정적 배열 래퍼 UnifiedStopIndex::nodeIdxInHour (24시간 인덱스)
std::queue<T> ds::Queue<T> 동적 원형 링 버퍼 Graph::reachable() BFS 탐색 큐
std::priority_queue ds::PriorityQueue<T, Cmp> ds::Vector 기반 이진 힙 Graph::shortestPath(), shortestPathTimeDependent()
std::unordered_map ds::HashMap<K, V> 분리 체이닝(Separate Chaining) 해시 테이블 idToIdx, stopToDense, StopDirectory
std::unordered_set ds::HashSet<K> HashMap<K, char> 기반 해시 집합 Graph::neighbors() 중복 정류장 제거
std::set<T> ds::OrderedSet<T> 자가 균형 AVL 이진 탐색 트리 Graph::routesAt() 노선명 정렬 및 중복 제거
std::pair / std::tuple ds::Pair<A, B> / 커스텀 구조체 값/이동 생성자 + 비교 연산자 Graph::shortestPath 힙 원소, TimeHeapItem
std::sort / stable_sort / reverse / find ds::sort / ds::stableSort / ds::reverse / ds::find 안정 병합 정렬(Merge Sort) 및 포인터 반복 경로 역순 정렬, 인접 후보 쌍 정렬, 중복 ID 확인

3. 기본 유틸리티 및 비교자

심볼 설명
ds::RemoveRef<T> / ds::move(x) 참조 제거 메타함수와 rvalue 캐스팅(<utility> 없이 이동 시맨틱 구현)
ds::swap(a, b) ds::move를 이용한 3-step 값 교환
ds::min(a, b) / ds::max(a, b) < 연산자 기반 최솟값·최댓값 반환
ds::Less<T> / ds::Greater<T> a < b 및 b < a 비교 함수 객체 (힙·정렬에 사용)
ds::Pair<A, B> first, second 멤버와 ==, <, > 사전식 비교 제공

4. 알고리즘 (Reverse / Find / MergeSort)

함수 시간 복잡도 동작 설명
ds::reverse(first, last) O(N) 양 끝 포인터/반복자를 안쪽으로 좁히며 ds::swap 수행
ds::find(first, last, value) O(N) [first, last) 범위에서 *it == value인 첫 반복자 반환(없으면 last)
ds::stableSort(first, last [, comp])
ds::sort(first, last [, comp])		 O(N log N) 임시 Vector<T> 버퍼를 사용하는 하향식 병합 정렬(Merge Sort). 동일 키의 상대 순서를 보존하는 안정 정렬

5. ds::Array<T, N>

고정 크기O(1) 접근

컴파일 타임 크기 N을 갖는 스택/인라인 배열 래퍼입니다(N == 0일 때도 안전하도록 최소 크기 1 보장).

주요 메서드설명
operator[](i), data(), begin(), end()연속 메모리 인덱스 접근 및 범위 기반 for 루프 지원
fill(val)모든 원소를 val로 초기화
size(), empty()고정 크기 N 및 공백 여부 반환

6. ds::Vector<T>

동적 배열분할 상환 O(1) push_back

::operator new로 원시 메모리를 확보하고 placement new로 원소를 생성/소멸합니다. 용량이 부족하면 2배(초기 8)로 재할당합니다.

주요 메서드시간 복잡도설명
Vector(), Vector(count), Vector(count, val)O(N)기본 생성 및 크기/초기값 지정 생성
push_back(val), emplace_back(args...)분할 상환 O(1)복사/이동 또는 제자리 생성으로 끝에 원소 추가
pop_back(), clear()O(1) / O(N)명시적 소멸자(~T()) 호출 후 크기 감소
reserve(newCap), resize(n [, val]), assign(n, val)O(N)예외 안전 이동 재할당 및 크기 조절
operator[](i), at(i), front(), back()O(1)at(i)는 범위 초과 시 std::out_of_range 발생
begin(), end(), data(), operator==O(1) / O(N)포인터 반복자 및 동등 비교

7. ds::Queue<T>

FIFO 원형 큐O(1) push / pop

head_와 tail_ 인덱스가 모듈러 연산으로 순환하는 원형 링 버퍼 기반 큐입니다. 가득 차면 2배(초기 16)로 확장하며 순서를 유지한 채 재배치합니다.

주요 메서드시간 복잡도설명
push(val)분할 상환 O(1)tail_ 위치에 원소 삽입
pop()O(1)head_ 위치 원소 소멸 후 인덱스 전진
front(), empty(), size(), clear()O(1) / O(N)선두 원소 조회 및 상태 확인

8. ds::PriorityQueue<T, Compare>

이진 힙O(log N) push / pop

ds::Vector<T> 위에 구현한 완전 이진 트리 기반 힙입니다. 기본 비교자 ds::Less<T>는 최대 힙이며, ds::Greater<T>를 전달하면 최솟값이 top()에 오는 최소 힙으로 동작합니다.

주요 메서드시간 복잡도설명
push(val), emplace(args...)O(log N)말단 삽입 후 siftUp()으로 힙 속성 복구
pop()O(log N)루트 제거 후 마지막 원소를 루트로 옮겨 siftDown() 수행
top(), empty(), size(), clear()O(1)최우선 원소 참조(const T&)

9. ds::Hash<K> (범용 해시 함수 객체)

<string> 헤더 의존 없이 정수형과 문자열형(std::string 등)을 모두 해싱하기 위해 SFINAE(IsByteBuffer<K>)를 사용합니다.

  • 정수 계열 키 (int, int32_t 등): SplitMix64 기반 64비트 비트 믹싱(mix64) 적용.
  • 바이트 버퍼 키 (.data()와 .size() 멤버를 가진 타입): 64비트 FNV-1a 해시 알고리즘 적용.

10. ds::HashMap<K, V, Hasher>

분리 체이닝 해시 테이블평균 O(1) 조회/삽입

2의 거듭제곱 크기 버킷 배열(bucketCount_)과 연결 리스트 노드를 사용합니다. 적재율(load factor)이 0.75를 초과하면 버킷 수를 2배로 늘려 rehash()합니다.

주요 메서드평균 복잡도설명
operator[](key), insertOrAssign(key, val)O(1)키가 없으면 기본값 노드 삽입 후 참조 반환
find(key), count(key)O(1)Iterator / ConstIterator 반환(it->first, it->second 프록시 지원)
reserve(n), clear(), size(), empty()O(N) / O(1)사전 버킷 확보 및 전체 노드 해제

11. ds::HashSet<K, Hasher>

해시 집합평균 O(1) 중복 검사

ds::HashMap<K, char, Hasher>를 감싼 집합 컨테이너입니다.

  • bool insert(key): 원소가 새로 삽입되면 true, 이미 존재하면 false를 반환합니다.
  • contains(key), count(key), reserve(n), clear(), size(), empty()를 제공합니다.

12. ds::OrderedSet<T> (자가 균형 AVL 트리)

AVL 이진 탐색 트리최악 O(log N) 삽입/탐색

모든 노드에서 좌우 서브트리 높이 차이(balanceFactor)를 [-1, 1] 범위로 유지하도록 LL·RR·LR·RL 회전을 수행합니다.

주요 메서드시간 복잡도설명
bool insert(key)O(log N)중복 없이 오름차순(<) 위치에 삽입 후 AVL 회전으로 균형 복구
bool contains(key)O(log N)이진 탐색으로 포함 여부 반환
toSortedVector()O(N)중위 순회(In-order traversal)로 정렬된 ds::Vector<T> 생성
