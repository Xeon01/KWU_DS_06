3. Python GUI와 Pathfinder 연동 및 UI 개선

A. Pathfinder 연동 및 안정화 (UI/bus_route_logic.py)

  • C++ 엔진 직접 호출: 기존 Python heapq 탐색을 find_paths_with_pathfinder()로 대체해 24시간 그래프 기반 최단 시간 경로(alpha=0.0)와 혼잡 회피 경로(alpha=4.0)를 함께 계산합니다.
  • 정적 링크 자동 빌드: Anaconda 등 외부 환경 실행 시 MinGW 동적 DLL 진입점 충돌(0xC0000139)을 막기 위해 Windows에서 -static 옵션으로 컴파일(kwu_ds_06_static_pathfinder.exe)합니다.
  • 인접 정류장 자동 폴백: find_nearby_stop_ids()로 출발·도착 정류장 반경 600m 내 최대 6개 인접 정류장을 후보로 전달해, 공항버스 전용(122000606 등)이나 반대 방향 정류장을 선택해도 연결 가능한 인근 정류장으로 경로를 찾습니다.
  • 출발/도착지 → 가까운 정류장 탐색: resolve_place_to_stop()을 추가해 위도·경도 좌표(역순 입력 자동 보정), 정류장명/ARS 번호 정확 일치, OpenStreetMap Nominatim 지오코딩, 부분 문자열 폴백 순으로 가장 가까운 정류장을 자동 선택합니다.

B. 대시보드 UX 및 20% 단위 혼잡도 시각화 (UI/dashboard.py)

  • 기본 경로 및 기본 시각 설정: 라디오 버튼의 기본 선택을 혼잡도 낮음 경로 우선으로 설정하고, 출발 시/분 기본값을 현재 시각(datetime.now())으로 초기화했습니다.
  • 여정 입력 UI 개선: 상단 장소/좌표 검색 폼에서 찾은 가장 가까운 정류장을 하단 출발·도착 정류장 선택 박스에 즉시 자동 입력하며, 폴백 탐색이 발생한 경우 안내 배너를 표시합니다.
  • Streamlit 호환성 및 디자인 정리: 구버전 Streamlit에서 TypeError를 일으키던 st.title(..., text_alignment=...)를 HTML 중앙 정렬 타이틀로 수정하고, 제목 앵커 링크(anchor=False)와 모든 이모지를 제거했습니다.
  • 지도 간선 및 구간 상세 표 5단계 색상 적용: 지도 위 각 버스 간선(folium.PolyLine)과 구간 상세 표의 행 배경을 구간별 혼잡도 20% 단위로 구분해 표시하고 하단 범례를 추가했습니다.
0~20% (파랑)
20~40% (초록)
40~60% (노랑)
60~80% (주황)
80~100% (빨강)
자료 없음 (회색)

4. 미운행 간선 및 결측 데이터 원인 분석 요약

  • bus_edges_혼잡도.csv 전체 40,619개 간선 중 혼잡도 공란 비율은 08시 11.5%(4,669건), 14시 12.8%(5,197건), 18시 12.3%(5,008건)였습니다.
  • 해당 간선들은 심야버스(N13 등 0~5시·23시만 운행), 새벽/맞춤버스(8146 등 3~6시만 운행), 공항·투어·미매칭 노선(6020, TOUR11, 새벽A148)으로, 기존에는 Edge::cost()의 defaultCongestion = 0.0 때문에 낮 시간대에도 우선 선택되는 문제가 있었습니다.
  • Pathfinder.cpp에서 !e.hasData() 간선을 탐색 대상에서 제외해 실제 운행 노선만으로 경로를 구성하도록 개선했습니다(단, 테스트 기준 14시 전 노선 중 부분 결측 노선은 0건으로 확인).
